# 보고서 제작기

예전에 만든 보고서(샘플)를 넣으면, 새 원고를 그 모양 그대로 만들어 준다. **AI 없이 프로그램만으로 동작**한다
(대표님 PC처럼 Claude를 쓰지 않는 곳에서도 그대로 쓸 수 있게).

> ★ **원고의 글자·숫자는 절대 바꾸지 않는다.**
> 값은 프로그램이 원본 셀·문단을 그대로 복사한다(다시 타이핑하지 않음). 엑셀 숫자는 셀에 보이는 모양 그대로
> (91.4%, 1,234, 2026-11-23) 옮긴다. 다 만든 뒤 **원본과 한 칸씩 대조**해 리포트로 보여 준다.
> 원본 파일과 기존 보고서는 덮어쓰지 않는다(항상 새 파일).

## 쓰는 법

1. 바탕화면 **「보고서 제작기」**(설치본) 또는 이 폴더의 **`보고서제작기.vbs`** 더블클릭.
2. 위에서 모드를 고른다.
   - **기존 보고서에 추가**: ① 지금까지 만든 보고서(.docx 또는 엑셀) → ② 이번에 넣을 원고
     → 새 파일이 생긴다. 이름에 `1-11호`가 있으면 `1-12호`로, 없으면 `_추가본`이 붙는다.
   - **새 보고서 만들기**: ① 제목(선택)·샘플 보고서(선택) → ② 원본 파일들(파일 하나 = 한 묶음/호)
3. 원고는 **파일 추가…**로 여러 개 넣을 수 있다. 메일·카톡에서 **복사한 글**은 붙여넣기 칸에.
4. (선택) **매호 이미지 폴더**를 고르면 호마다 그 호 그림을 넣는다 → 아래 「매호 이미지」.
5. **만들기** → `결과 파일 열기` / `원본 대조 결과 보기`.
   - ✔ 초록: 원본 글자·숫자가 모두 그대로 들어감.
   - ⚠ 빨강: 다른 곳이 있음 → 대조 결과가 자동으로 열린다. 빨간 항목을 결과 파일에서 꼭 확인할 것.

## 어떻게 만드나 (`engine.py`)

**워드 샘플**
1. 샘플에서 **반복되는 묶음 제목**을 찾는다: 숫자만 다르고 모양이 같은 짧은 문단이 2번 이상(`□ 1호 (…)`, `2. 2026년 10월 운영 실적`, `제 5회 정기회의 (…)` 등).
2. **마지막 묶음**을 복제하고, 새 원고를 **줄 단위**로 맞춘다(줄 = 엑셀 행 / 문단 / 표 행).
   - 글자가 같은 줄(대상수·건수 같은 항목명)은 그대로, 값 줄은 원본 값을 칸 순서대로 넣는다.
   - 원고 줄이 많으면 **바로 앞 줄 모양**(표 행·글머리 등)을 복제, 적으면 남는 줄을 지운다.
   - 여러 묶음에 똑같이 나오는 문구(`※ 방문자수는 GA 기준`, `▼ 반응 결과`)는 **고정 문구**로 보고 덮어쓰지 않는다.
     단 원고에 없고 그 아래 표가 통째로 빠지면 소제목도 같이 지운다.
   - 샘플에 맞는 칸이 없는 원고 줄은 그 자리에 한 문단으로 이어 적는다(칸 사이 두 칸 띄움, 안내에 표시).
3. **제목**: 묶음마다 1씩 늘던 숫자 중 첫째 = 호 번호 → 원고의 `Vol.12`/`제12호`, 없으면 앞 번호+1.
   날짜(`2026.11.09`, `2026. 3. 4.`, `2026년 11월`)는 원고에서 처음 나온 날짜로, 쓰는 모양은 샘플 그대로.
   그 밖에 1씩 늘던 숫자(월 등)는 +1. 못 찾으면 그대로 두고 안내.
4. **새 보고서 + 샘플**: 표지·개요(첫 묶음 앞)는 샘플 그대로 두고 묶음만 새로 만든다. 원고는 호 번호 → 날짜 순으로 정렬.

**엑셀 샘플**(호마다 시트): 원고 엑셀 시트를 값·서식·병합·열 너비째 복사해 붙인다. 시트 이름은 가장 많이 반복되는
이름 모양(`N호`)의 번호만 바꾼다(`Sheet12` 같은 빈 시트에 속지 않음). 같은 이름이 있으면 막는다(중복 추가 방지).

**샘플 없음**: 원본의 표·글을 그대로 옮긴 기본 워드 보고서(파일마다 제목 + 표/문단).

## 매호 이미지 (`engine.place_images`)

- 피그마에서 **프레임 가로 1000px → Export 2x**(가로 2000px)로 저장해 한 폴더에 모아 둔다. PNG·JPG 다 된다.
- **파일 이름 = 호 번호**: `26_12호.png` → 12호. '호' 바로 앞 숫자가 호, 그 앞(`26_`)은 연도.
  한 호에 여러 장이면 `26_12호_1.png`, `26_12호_2.png` 순서대로. 같은 호가 여러 해 있으면(`25_1호`·`26_1호`)
  원고 날짜의 연도 것, 날짜가 없으면 최근 연도 것을 쓰고 안내에 적는다.
- 넣는 자리: 샘플 마지막 묶음에 **그림이 있으면 그 자리·그 폭 그대로 그림만 바꾼다**(세로는 비율대로).
  더 많으면 마지막 그림 뒤에 같은 폭으로 이어 넣고, 적으면 남는 그림을 뺀다.
  샘플에 그림이 없으면 **호 제목 바로 아래에 본문 폭**으로(가운데 정렬). → 처음 한 번 워드에서 자리·크기를 잡아 두면 다음 호부터 그대로 따라간다.
- 그 호 그림이 폴더에 없으면 샘플 그림(지난 호 그림)이 남지 않게 빼고 안내에 적는다.
  이미지 폴더를 비워 두면 예전처럼 샘플 그림이 그대로 복제된다.
- 크기: 가로 2000px 넘으면 줄인다. PNG는 PNG 그대로, 투명 부분 없는 1.5MB 넘는 PNG(사진)만 JPG(품질 90)로. webp·bmp·tif는 PNG로.
- 엑셀 보고서: 그 호 첫 시트의 표 아래(A열)에 가로 800px로. 샘플 없는 기본 보고서: 원고의 Vol.N·제N호(없으면 원고 파일 이름의 N호)로 찾아 제목 아래에.
- **이미지만 넣기**(`engine.add_images`): 「기존 보고서에 추가」에서 ② 원고를 비워 두고 이미지 폴더만 고르면,
  보고서에 이미 있는 호 제목의 번호(묶음마다 늘어나는 숫자)로 그 호 그림을 찾아 넣은 `…_이미지.docx`를 만든다.
  그림이 없는 호는 그대로 둔다. 글자는 하나도 바꾸지 않고, 기존 내용 보존 대조로 확인한다. 엑셀은 `N호` 시트마다(이미 그림이 있는 시트는 건너뜀).
- 무엇을 넣었는지(`이미지 12호 ← 26_12호.png (2400×1600 → 2000×1333)`)는 대조 리포트 「안내」에.

## 원본 대조 (`engine.verify`)

- **순서 대조**: 원고 줄이 결과(새로 붙은 부분)에 **같은 순서로, 칸 글자 그대로** 있는지.
- **칸·문단 개수 대조**: 기존 보고서에 있던 몫을 빼고 센다. 긴 글(6자 이상)은 다른 글과 한 문단에 합쳐져도 글자가 같으면 인정, 짧은 값(`-`, `0`, `3.2%`)은 칸 그대로여야 한다.
- **숫자 개수 대조**: 빠진 숫자 / 원본에 없는데 생긴 숫자. 프로그램이 붙인 제목과 (새 보고서) 샘플 표지의 숫자는 허용.
- **기존 내용 보존**(추가 모드): 기존 보고서의 문단·칸이 하나라도 바뀌거나 사라지면 표시.
- 리포트: 결과 파일 옆 `<결과이름>_원본대조.html`. 작업 중간 파일: `작업기록\<시각>\`.
- 명령줄: `python engine.py verify <결과> <원본…> --base <기존보고서> --out 대조.html`
  (만들기: `python engine.py add <기존보고서> <원고…> --img-dir <이미지폴더>`)
- 그림은 글자 대조 대상이 아니다 — 넣은 그림 목록은 리포트 「안내」에서 확인.

## 시험

`python test_engine.py` — 가상 데이터로 50여 개 확인(셀 표시 형식, 줄 늘어남/줄어듦, 고정 문구, 글머리 모양,
여러 원고 한꺼번에, 변조 잡아내기, 워드 원고·붙여넣은 글, 샘플 없음, 매호 이미지 이름·자리·폭·축소·연도 구분·엑셀).
실제 보고서로: `python test_engine.py <기존보고서.docx> <추가원고.xlsx> <정답.docx>`.
(실제 발송결과 보고서 1-11호 + 12호 리포트 → 1-12호와 글자 동일, 1~12호 원고 12개를 섞어 넣어 새로 만들어도 동일 — 2026-11-26 확인)

## 못 하는 것

- **샘플이 구형 한글(.hwp)·한글(.hwpx)·파워포인트·PDF** 이면 안 된다 → 한글에서 [다른 이름으로 저장 → 워드 문서(*.docx)]로 바꿔 넣는다.
  (원고로는 hwp·hwpx·pptx·pdf 다 읽는다)
- 원고 파일 **안에 든 그림**은 꺼내 쓰지 않는다 — 그림은 매호 이미지 폴더로만 넣는다.
- 그림의 SVG·PDF 형식은 안 된다(피그마에서 PNG·JPG로 저장).
- 목차·합계·표지 날짜처럼 추가분에 따라 바뀌어야 할 곳은 고치지 않는다.
- 스캔 이미지 PDF(글자 레이어 없음)는 읽지 못한다.

## 설치 · 배포 (대표님 PC 등)

- **설치**: `보고서제작기_설치.bat` 하나만 보내 더블클릭 → 파이썬(없으면 winget 으로)·구성요소 설치,
  `%LOCALAPPDATA%\보고서제작기`에 프로그램, 바탕화면 아이콘 생성. 시험 설치: `install.ps1 -Dir <폴더> -NoShortcut`.
- **자동 업데이트**: 설치본은 켤 때마다 GitHub `version.txt`를 보고 바뀌었으면 새 파일을 받는다(`update.ps1`).
  실패해도 지금 버전으로 그냥 켜진다. 내 설정·작업기록은 건드리지 않는다. 개발 폴더(이 폴더)는 업데이트하지 않는다(`installed.txt` 없음).
  GitHub raw 캐시 때문에 push 후 반영까지 3~5분.
- **새 버전 내보내기**: 이 폴더에서 `.\release.ps1 -Note "고친 내용"` → version.txt 올리고 커밋·push.
- 저장소: `github.com/pagecraft-tools/report-maker` (공개, 코드만 — 클라이언트 파일은 올리지 않는다).
